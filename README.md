Cupboard provides code, different frameworks and utilities for minecraft mods
Features:
- Json config framework
- Full stacktrace crashes
- error logging for commands
- Debug logging for sync chunk loading 
- Prevents common entity loading crashes with invalid rotations
## Installation

1. Install the required mod loader.
2. Download the mod from the official CurseForge page.
3. Place the `.jar` file in your `mods` folder.

> This mod is officially distributed only through CurseForge. Downloads from other websites may be outdated, modified, or unsafe.
